Instalación del CMS — Babidibu Records

Este documento explica cómo instalar el panel de administración del sitio babidiburecords.com.

Paso 1 — Editar el archivo de configuración

Antes de subir, abrí el archivo php-admin/config.php con cualquier editor de texto y reemplazá estas líneas con los datos de la base de datos de Hostinger:

define('DB_HOST', 'localhost');
define('DB_NAME', 'NOMBRE_DE_TU_BASE_DE_DATOS');
define('DB_USER', 'USUARIO_DE_TU_BASE_DE_DATOS');
define('DB_PASS', 'CONTRASEÑA_DE_TU_BASE_DE_DATOS');

Hacé lo mismo en setup/install.php, reemplazando estas líneas:

'host' => 'localhost',
'db'   => 'NOMBRE_DE_TU_BASE_DE_DATOS',
'user' => 'USUARIO_DE_TU_BASE_DE_DATOS',
'pass' => 'CONTRASEÑA_DE_TU_BASE_DE_DATOS',

Paso 2 — Ejecutar el instalador

Abrí en el navegador:

https://babidiburecords.com/setup/install.php

Si la instalación es exitosa, vas a ver un mensaje verde con el email y contraseña del panel.

Credenciales iniciales del panel:
Email: info@babidiburecords.com
Contraseña: BabidibuAdmin2024!
(Cambiarla después del primer login)

Paso 3 — Eliminar el instalador

Importante: Después de instalar, eliminá el archivo setup/install.php del servidor. Es un riesgo de seguridad dejarlo ahí.

Paso 4 — Acceder al panel

El panel de administración queda disponible en:

https://babidiburecords.com/php-admin/login.php

¿Problemas?

Si aparece un error rojo, probablemente los datos de la base de datos no son correctos. Verificar nombre, usuario y contraseña en Hostinger → Bases de datos MySQL.
